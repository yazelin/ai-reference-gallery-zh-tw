四庫怎麼一起用

  • 姿勢線稿或深度圖決定動作，服裝圖決定穿著，臉部圖決定長相。三種參照圖分別放進生圖工具對應的參照欄位。
  • 同一個角色要連續出好幾張時，固定用同一張臉、同一套服裝，姿勢換同一個姿勢編號的不同角度。
  • 姿勢線稿和深度圖沒有臉、服裝、背景；服裝圖沒有人物。缺的部分用提示詞或其他參照圖補上。

給 AI 用

對 AI 說「讀 https://yazelin.github.io/ai-reference-gallery-zh-tw/llms.txt，幫我找一個跪坐回頭的姿勢、一套冬天的大衣、一張短髮的臉」即可。要裝成 agent skill，見 GitHub 上的說明。
