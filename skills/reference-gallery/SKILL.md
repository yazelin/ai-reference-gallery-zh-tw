# AI 繪圖參考圖庫

資料來自四個日文原站（[姿勢](https://ai-pose-gallery.pages.dev/)、[depth 姿勢](https://ai-pose-depth-gallery.pages.dev/)、[服裝](https://ai-costume-gallery.pages.dev/)，作者 ギア；[臉部](https://ai-portrait-gallery.pages.dev/)，作者 あぎ），繁中翻譯版每日同步。網頁入口：<https://yazelin.github.io/ai-reference-gallery-zh-tw/>

## 四個庫

| 庫名 | 內容 | 用在生圖工具的哪裡 |
|---|---|---|
| `pose` | 無臉灰色人台線稿，1,439 張（3:4，900×1200） | 姿勢參照、構圖參照、ControlNet lineart 或 openpose 前處理 |
| `depth` | 同一批姿勢的深度圖，越白越靠近鏡頭，id 與 `pose` 相同 | 深度參照、ControlNet depth |
| `costume` | 只有服裝、沒有人物，1,407 套（2:3） | 服裝參照、換裝 |
| `portrait` | AI 虛構人物。`face` 是正面素色背景的臉，`styling` 看得出服裝、髮質、氛圍 | 角色參照、臉部參照 |

## 怎麼找

```bash
python3 ref.py search <庫> 關鍵字 [關鍵字...] [選項]
```

- 多個關鍵字要全部符合。預設列 30 筆，`--limit 0` 列全部。
- `pose`／`depth`：比對 id、系列、分類、姿勢名稱。`--angle` 是 `正面`、`從上方`、`從下方`、`側面`、`斜側`；`--line` 是 `全身1人・標準系`、`全身1人・性感系`、`上半身1人`、`2人交纏`。分類有站立、坐姿、蹲姿、跪立、趴躺、前傾、扭轉、後仰・反弓、可愛系等。找不到時換同義詞，例如「托腮」「撐地」「抱膝」「回頭」「撥髮」。
- `costume`：關鍵字是英文單字（例如 `coat`、`lace`、`denim`），常見的中文顏色、單品、材質也會自動換成英文（`白`、`大衣`、`蕾絲`、`丹寧`）。`--cat` 是 `春`、`夏`、`秋`、`冬`、`內衣`、`派對`、`泳裝`、`性感`。
- `portrait`：比對髮型名稱。`--section` 是 `face` 或 `styling`；`--hair` 是 `短髮`、`及肩`、`中長髮`、`長髮`、`未分類`。
- 每行輸出 id、分類資訊與縮圖網址。

不想跑腳本，也可以直接讀資料檔：`pose/poses.json`、`depth/poses.json`、`costume/costumes.json`、`portrait/faces.json`（都在網頁入口底下）。每筆都有 `thumb`（縮圖）和 `image`（原尺寸 PNG）網址。

## 怎麼用

1. 用 search 找候選。看圖挑選用縮圖網址就夠了，不必下載。
2. 挑定之後，只下載要用的那幾張原尺寸 PNG：
   ```bash
   python3 ref.py get <庫> <id> [<id>...] -o refs
   ```
   檔名是 `<庫>_<id>.png`。一次最多 10 張。
3. 姿勢線稿或深度圖決定動作，服裝圖決定穿著，臉部圖決定長相，分別放進生圖工具對應的參照欄位。
4. 線稿和深度圖沒有臉、服裝、背景，服裝圖沒有人物，缺的部分用提示詞或其他參照圖補上。用線稿時要明說「姿勢照參考圖，不要畫出人台的關節線與灰色」。
5. 同一個角色要連續出好幾張時，固定同一張臉、同一套服裝，姿勢用同一個 `pose_no` 的不同角度，比較容易一致。

## 規範（原站注意事項）

- 可免費用於自己的作品，商業使用、編輯、參考都可以，不必標註出處。
- **禁止再散布圖片本身**，原尺寸和加工後的都算。下載的 PNG 只能留在本機當參考，不要 commit 進公開 repo，也不要放上網站或分享出去。臉部庫是 CC0，但原作者同樣請大家不要再散布圖片本身，照一樣的方式處理。
- **`pose`、`depth`、`costume` 禁止批次下載**，用工具自動抓取也算。只下載這次真的要用的幾張，不要為了「先存起來」整批抓。
- 不得用於表現或冒充真實人物、未成年人，也不得用於違反公序良俗的用途。
- `全身1人・性感系`、`2人交纏` 系列，以及服裝的 `內衣`、`性感` 分類含性暗示內容。使用者沒要求時，從其他系列與分類找。
